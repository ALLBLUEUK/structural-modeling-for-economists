## 1. 经济问题与机制

研究问题（示意校准下的模型含义）：
- 情形 S1（单边）：地区 A 对来自地区 B 的制造业（MAN）进口加征 10% 从价关税，其余关税不变；
- 情形 S2（报复）：在 S1 基础上，B 对来自 A 的 MAN 进口加征 10% 关税；R 在两种情形下均不改变政策。

模型给出三地区的双边贸易流、分部门产出与就业、实际吸收（福利）的变化，并做福利分解。

可检验的模型命题：
- P1：S1 中 A 自 B 的 MAN 进口（按出厂价值计）下降，A 的 MAN 支出向本地和 R 转移（贸易转移）。
- P2：S1 中 B 的相对工资下降（ŵ_B/ŵ_A < 1），即 A 获得贸易条件改善。
- P3（待检验假设，非验收断言）：S2 相对 S1，A 的福利下降；B 的福利变化方向不确定。因 10% 低于数量级约为 1/ε 的最优关税，B 的报复可能使 B 自身获益。

机制：Armington 设定下产品按产地区分，CES 替代。关税抬高 B 产品在 A 的含税价格，A 的需求转向本地与 R（贸易转移）；B 面临需求下降，工资相对下降，A 由此获得贸易条件收益与关税收入，同时承受消费扭曲的效率损失。单边关税的净福利取决于两者大小。

与文献的距离：本模型是对 Dekle, Eaton and Kortum (2008) 精确变化方法与 Costinot and Rodríguez-Clare (2014) "Trade Theory with Numbers: Quantifying the Consequences of Globalization"（Handbook of International Economics, Vol. 4）多部门、无投入产出联系版本的复制，加上双边关税与关税收入回流的小扩展。相关文献：Armington (1969)、Anderson (1979)、Arkolakis, Costinot and Rodríguez-Clare (2012)、Ossa (2014) 的关税战量化、Caliendo and Parro (2015) 的含投入产出多部门模型。

与实证的张力：2018–2019 年美中关税的实证研究（Amiti, Redding and Weinstein 2019；Fajgelbaum, Goldberg, Kennedy and Khandelwal 2020）发现关税几乎完全传递到进口价格。本模型中出口方工资的一般均衡调整会带来贸易条件效应，因此模型不能被用来“解释”真实的贸易战结果。

不包含的机制：投入产出联系、部门异质的生产率冲击、资本积累、策略博弈与谈判、内生贸易赤字、政府支出、名义刚性。

## 2. 时间环境

静态比较（基期均衡 → 反事实均衡）；无不确定性。

## 3. 代理人

### 3.1 代表性家庭（每地区一个）
- 偏好：上层 Cobb-Douglas（部门份额 α_j^s，Σ_s α_j^s = 1），下层对各产地 CES，替代弹性 σ_s = 1 + ε_s
- 收入：劳动收入 w_j L_j + 关税收入 R_j（基期 D_j = 0，见 §7 赤字剔除）
- 劳动在地区内部门间自由流动，地区间不流动

### 3.2 生产者（每地区每部门，完全竞争，线性技术）
- 单位成本与工资成正比；冰山成本 d_ij^s ≥ 1；反事实中 d̂ = 1，仅在 ACR 解析检验中 d̂ ≠ 1

### 3.3 政府
- 征收从价关税 t_ij^s（进口方 j 对来自 i 的 s 部门产品，t_jj^s = 0），收入以总额方式返还本地家庭；无政府支出

## 4. 变量分类表（水平量与变化率）

| 符号 | 类型 | 含义 |
|---|---|---|
| X_ij^s | 数据（水平） | 基期 i → j 的 s 部门贸易流，按出厂价计 |
| Y_i | 数据（水平） | 基期产值 = w_i L_i = Σ_j Σ_s X_ij^s |
| E_j | 数据（水平） | 基期总支出（含税）= Σ_i Σ_s X_ij^s (1 + t_ij^s) |
| D_j | 数据（水平） | 贸易赤字 = E_j − Y_j − R_j，符号：正为赤字；Σ_j D_j = 0 |
| α_j^s | 参数 | 部门支出份额 = Σ_i X_ij^s(1+t_ij^s) / E_j |
| λ_ij^s | 参数 | **含税**支出份额 = X_ij^s(1+t_ij^s) / Σ_k X_kj^s(1+t_kj^s) |
| L_i^s | 数据 | 部门就业 L_i^s = Σ_j X_ij^s / w_i（以基期 w_i = 1 计量） |
| ε_s | 参数 | 贸易弹性 |
| t, t' | 外生 | 基期与反事实关税 |
| d̂_ij^s | 外生 | 冰山成本变化（仅 ACR 检验） |
| ŵ_i | 内生（变化率） | 工资变化 |
| λ'_ij^s | 内生（水平） | 反事实含税支出份额 |
| P̂_j^s | 内生（变化率） | 部门价格指数变化 |
| E'_j, R'_j | 内生（水平） | 反事实总支出、关税收入 |

## 5. 方程系统（精确变化形式）

记 c_ij^s = ŵ_i d̂_ij^s (1 + t'_ij^s)/(1 + t_ij^s)。

1. 支出份额：λ'_ij^s = λ_ij^s (c_ij^s)^{−ε_s} / Σ_k λ_kj^s (c_kj^s)^{−ε_s}
2. 价格指数：P̂_j^s = [Σ_k λ_kj^s (c_kj^s)^{−ε_s}]^{−1/ε_s}
3. 支出与关税收入（闭式）：令 ρ_j = Σ_s α_j^s Σ_i [t'_ij^s/(1+t'_ij^s)] λ'_ij^s，则 E'_j = (ŵ_j Y_j + D'_j)/(1 − ρ_j)，R'_j = ρ_j E'_j。赤字剔除步骤取 D'_j = 0，之后的政策实验以剔除后的均衡替换基期的 X、Y、E（此后 D = D' = 0）
4. 收入出清：ŵ_i Y_i = Σ_j Σ_s λ'_ij^s α_j^s E'_j / (1 + t'_ij^s)
5. 计价单位：Σ_i ŵ_i Y_i = Σ_i Y_i
6. 福利（实际吸收变化）：Ŵ_j = (E'_j/E_j) / Π_s (P̂_j^s)^{α_j^s}

全量计数（3 地区 × 2 部门）：内生变量 ŵ(3) + λ'(18) + P̂(6) + E'(3) + R'(3) = 33；方程 (1)18 + (2)6 + (3)6 + (4)3 + (5)1 = 34。由 Walras 律（前提：Σ_j D_j = 0、Σ_s α_j^s = 1），(4) 中有 1 条冗余，独立方程 33 条，与未知量相等。✅ 给定 ŵ，(1)(2)(3) 为显式表达，实际求解只需对 ŵ 解 (4) 去一条加 (5)。

计价单位说明：D_j 为名义固定时系统对 ŵ 不是零次齐次的，计价单位选择会影响实际结果。本模型在基期先把 D 剔除为 0（§7），因此计价单位中性；验证中以“改用 ŵ_A = 1 为计价单位、实际结果不变”检验。

福利分解（报告用，基期 D = 0、t = 0 时 E_j = Y_j）：ln Ŵ_j = ln ŵ_j + ln(1 + R'_j/(ŵ_j Y_j)) − Σ_s α_j^s ln P̂_j^s，三项依次为“要素收入（工资）变化”“关税收入”“价格指数变化”，三项可加。

## 6. 函数形式

上层 Cobb-Douglas、下层 CES；部门就业变化 L̂_i^s = (部门 s 出厂销售额变化) / ŵ_i，满足 Σ_s L_i^s L̂_i^s = L_i（自洽检验）。

## 7. 参数与数据

| 项 | 值 | 来源 |
|---|---|---|
| ε_MAN, ε_OTH | 4, 4 | Simonovska and Waugh (2014)；在 Armington 设定下贸易弹性 ε = σ − 1；两部门取同值为基准简化，稳健性扫描 ε_MAN |
| 基期关税 t | 0（简化） | 声明：基期无关税 |
| 基期贸易流 X | 示意数据（3 地区 × 2 部门） | **示意数据，非真实统计**；登记于 `data/calibration/armington_tariff/manifest.json` |
| 赤字剔除 | 按 DEK (2008) 先求解 D' = 0 的反事实，作为“剔除赤字的基期” | 标准做法；之后所有政策实验以此为基期 |

## 8. 求解方法

- 对 ŵ 用 `scipy.optimize.root`（hybr）求解；独立第二求解器为阻尼超额需求迭代；两者差 < 1e-9
- 方程残差容差 1e-10
- 稳健性：ε_MAN ∈ {2, 3, 4, 6, 8}（ε_OTH = 4），报告 A 在 S1 中福利变化的符号翻转临界值（如存在）
- 数值最优关税：A 对 B 的 MAN 关税在 [0, 0.6] 网格上的福利最大点（仅数值报告，不与闭式公式比对）

## 9. 验证目标（均不依赖结果的符号；v3 按 numerics-reviewer 与 code-reviewer 意见重构）

计入通过判定的检验：
1. 赤字剔除后各地区贸易余额：max|D_j| / ΣY < 1e-9
2. 零冲击（从扰动初值出发求解）：t' = t 时 |ŵ − 1|、|Ŵ − 1| < 1e-12
3. Walras 律：全部出清方程（含被删去的一条）在解处残差 < 1e-10（另用插件 `scripts/check_walras.py --tol 1e-9` 复核）
4. 计价单位中性：改用 ŵ_A = 1，Ŵ 不变（差 < 1e-9）
5. 独立实现交叉核对：另写一个水平量形式的求解器（以位移参数校准，Levenberg–Marquardt 求解），与精确变化法的工资与福利一致（差 < 1e-9）
6. 复合检验：0 → t1 → t2 与 0 → t2 的福利变化一致（差 < 1e-9）
7. 部门就业自洽：Σ_s L_i^s L̂_i^s = L_i；福利分解各项之和等于 ln Ŵ（差 < 1e-9）
8. 两个求根器一致（差 < 1e-9；二者共享方程，只检验求根）
9. 命题 P1、P2 作为方向检验；P3 仅报告

仅作展示、不计入判定：会计恒等式（世界赤字和、收入 = 销售、支出恒等式）、ACR 公式一致性（在单部门、D = 0 下为代数恒等式，不检验求解器）
