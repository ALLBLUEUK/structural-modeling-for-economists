专项核对：

1. **关税楔子位置：正确。**
   - 消费者面对的进口价为 p_i(1+t_ij)，p_i = ŵ_i·d_ij（出厂价）。
   - 所以 λ' 与 P̂ 中使用 ŵ_iτ̂_ij 是对的，τ̂ = (1+t')/(1+t)。
   - 出口商收入是含税支出除以 (1+t')，即 (4) 中的 X/(1+t) 写法也正确。
   - 关税收入 t'/(1+t') × 含税支出，正确。
2. **前提缺口（必改 2）：**
   - 上述一切成立的前提是 λ_ij^s 定义为含税支出份额，即 λ_ij = X_ij(1+t_ij)/Σ_k X_kj(1+t_kj)。
   - spec 把 X_ij^s 写成“出厂价”，却没给 λ 的定义。
   - 在 t = 0 的基准下这不影响数值，但方程写成了一般 t，必须明确。否则按“λ = X/ΣX（出厂价份额）”实现会在 t ≠ 0 时算错。
3. **E' 闭式（spec 声称“闭式求出”但没写出）。**
   - R'_j = ρ_j E'_j，其中 ρ_j = Σ_s α_j^s Σ_i [t'_ij^s/(1+t'_ij^s)] λ'_ij^s。
   - 代入 (3)：**E'_j = (ŵ_jY_j + D_j)/(1 − ρ_j)**。
   - 在给定 ŵ 的条件下，λ' 由 (1) 单独算出，不依赖 E'，所以这个闭式确实成立且不循环。ρ_j < 1 在合理关税下自动满足。
   - 这条必须写进 spec，否则实现者可能把 R' 与 E' 当联立非线性方程求解，或者用 R' = Σ t X' 却漏掉对 E' 的反馈。
4. **未定义的符号（必改 2）：**
   - Y_j、E_j、α_j^s、D_j 的符号约定、L_j 都没有出现在变量表中。
   - Y_j 应定义为 w_jL_j = Σ_j Σ_s X_ij^s。
   - E_j 应定义为 Y_j + D_j + R_j。
   - D_j > 0 表示赤字。
   - α_j^s = (j 国对 s 的含税总支出)/E_j。
5. 方程 (1)–(4) 中出现的 t_jj（国内“关税”）必须明确为 0。
6. 国内部门内部自由流动、线性技术：(4) 只需国家层面出清，不需要分部门出清，推导正确（部门工资相同）。

## 三、状态-控制分类

- 静态模型，无状态变量、无控制变量的时间维度、无外生过程，故该项不适用。时点冲突：无。
- 外生：t'、D_j（名义固定）、ε、d_ij（不变）、基期数据 X、Y、α、λ。
- **缺口（必改 1）：**
  - 方程中没有 d̂_ij，所以“冰山成本冲击”在现有方程里无法表达。
  - 这直接使验证目标里的 ACR 检验无法实施（见第五节）。

## 四、FOC 推导抽查

- 家庭问题：max Π_s (Q_j^s)^{α_j^s}，Q^s = [Σ_i q_ij^{(σ−1)/σ}]^{σ/(σ−1)}，预算为 Σ p_ij(1+t_ij) q_ij = E_j。
  - 上层 CD 给 P^sQ^s = α^sE。
  - 下层 CES 给 λ_ij = [p_ij(1+t_ij)]^{1−σ}/Σ_k[...]^{1−σ}，即 [..]^{−ε}。
  - 取对基期的 hat 并消去常数（d、技术、偏好参数），得到 (1)–(2)。**与 spec 一致 ✅**。
- 完全竞争 + 线性技术：p_ij = w_i d_ij/A_i。hat 后为 ŵ_i（A、d 不变）。✅
- 福利：间接效用 V_j = E_j/Π_s(P_j^s)^{α_j^s}（CD 上层，CES 下层，价格指数含关税）。
  - 所以 Ŵ_j = (E'_j/E_j)/Π_s(P̂_j^s)^{α_j^s}，(6) 正确 ✅。
  - E 含关税收入 R 与赤字 D：这是“实际吸收（absorption）”的变化，也就是效用变化。
  - spec 称之为“实际收入”，建议改称“实际支出 / 效用”，因为含 D 与 R。
  - 前提：E_j 基期为 Y_j + D_j + R_j，与 (3) 的定义一致，且 E、E' 使用同一计价单位。
- 计价单位与 D 的关系（必改 4 的一部分）：
  - D_j 取名义固定，所以系统对 ŵ 不是零次齐次的：E' = (ŵY + D)/(1−ρ)，D 项不随 ŵ 缩放。
  - 因此 (5) 不只是一个“标准化”，它决定了 D 的实际价值。换一个计价单位（例如某国工资）会改变解和福利，当 D ≠ 0 时。
  - spec 选用世界要素收入不变作计价，是合法选择，但须声明“结果相对于该计价单位，D 以此计价固定”。
  - D = 0 时系统齐次，计价无关。
- 计价单位自身：(5) 为 Σŵ_iY_i = ΣY_i，即以世界劳动收入为计价，**可行 ✅**。注意它与 Walras 冗余的是 (4)，不是 (5)，替换方案正确。

## 五、稳态残差（解析）

静态模型无稳态，改查“零冲击”与“ACR 特例”解析性质：

- **零冲击 t' = t：**
  - 取 ŵ = 1，则 τ̂ = 1、λ' = λ、P̂ = 1、R' = R、E' = E（需基期满足 E_j = Y_j + D_j + R_j）。
  - (4) 右端 = Σ_jΣ_s λ_ij^sα_j^sE_j/(1+t) = Y_i，残差 0。(5) 残差 0。Ŵ = 1。**成立 ✅**，前提是基期 SAM 平衡。
  - 基期平衡条件在 spec 验证目标里漏了 R：“支出 = 收入 + 赤字”在 t ≠ 0 时应为“支出 = 收入 + 关税收入 + 赤字”。
- **ACR 检验 Ŵ_j = λ̂_jj^{−1/ε}（单部门、冰山成本冲击、无赤字）：**
  - 推导：D = 0、t = t' = 0 时 E' = ŵ_jY_j，故 Ŵ = ŵ_j/P̂_j。
  - 又 λ̂_jj = (ŵ_jd̂_jj/P̂_j)^{−ε}，当冲击在国际贸易成本（d̂_jj = 1）时 λ̂_jj = (ŵ_j/P̂_j)^{−ε}，即 Ŵ = λ̂_jj^{−1/ε}。
  - **公式本身对所述特例有效 ✅**，指数 −1/ε 与 ε = σ−1 一致。
  - **但 spec 当前方程无法跑这个检验：** 方程没有 d̂，且 §3.2 写“冰山成本反事实中不变”，与“冰山成本冲击”的检验矛盾（必改 1）。
  - 条件需写全：(i) 单部门；(ii) D_j = 0（所有国家）；(iii) 所有 t = t' = 0（带关税时福利公式多出关税收入项，不再是 λ̂_jj^{−1/ε}）；(iv) 冲击不含 d_jj 本身或 j 的生产率。
  - 若想在带关税的主情形上做解析检验，需要用 ACR 的含税扩展公式，并要求以带关税收入的 λ̂ 表达；本 spec 未给出，不建议当作解析基准。
