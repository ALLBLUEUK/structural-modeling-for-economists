## 求解器选择

- 选用：家庭问题 EGM（Carroll 2006）+ Young (2010) 彩票法分布 + Brent 法求 r（网格随 φ(r) 重建）。
- 与模型类是否匹配：通过。Aiyagari / Bewley 的稳态问题用 EGM + 非随机模拟 + 一维根求解是标准且合适的方案；稳态无需 SSJ。
- 说明：EGM 每次 Brent 迭代从同一初值冷启动，没有暖启动；只影响速度（每场景约 1.3 s），不影响正确性。
- 边界：借贷约束是唯一的非光滑点，EGM 对它处理正确（低于内生网格下端的点取 a' = a[0]）。内生网格上端以外 `np.interp` 将策略钳在 a_max，只在质量为 0 的区域生效（见下 mass_at_grid_top）。

## 网格 / 初值

- 资产网格：n_a = 400，幂次 2，[−φ, 200]。
  - 约束端：首个间距约 1.3e-3；b = 0 和 b = 8 都是这样。约束附近有 11 个点落在 [0, 0.02] 内，密度充分。
  - 均值附近：均衡 K ≈ 6，该处间距约 0.17–0.25，是网格最粗、而质量最集中的地方。一半格点（索引 > 200，即 a > 50）落在累计质量仅 2.5e-6 的区域，a_max = 200 过于宽松，网格被浪费。
  - 上端质量：所有场景 mass_at_grid_top = 0（下溢，实际 < 1e-30），远小于 1e-8，合规。
  - 重跑检验（Rouwenhorst 7 状态，b = 0 / b = 8）：

## 收敛

- EGM：572–578 次迭代（上限 5000），最终 sup 差 9.6e-11–9.9e-11，低于容差 1e-10，收敛。迭代次数偏多，原因是 β(1+r) ≈ 0.992–0.995 非常接近 1，压缩系数接近 1。σ→0 极限场景 536 次。合理，非问题。
- 平稳分布：
  - 修订后的例程先用稀疏线性方程组直接解 (T' − I)d = 0，再迭代打磨。迭代只跑 1 次，一步 sup 差 1e-17–2e-17。
  - 此处 dist_converged 实际检验的是残差 ‖T'd − d‖∞，不是误差。但直接解给出了良条件的结果，下面的资源约束残差 1e-14 量级可作旁证。
  - 对比首轮 v0：纯迭代需 2479–4874 次，停在 ~1e-12 的步差，资源约束残差 3e-10–2e-9，σ→0 场景迭代 100000 次后 sup 差 3.4e-7 仍未收敛，validated = False。
  - 修订后资源约束残差降到 1e-13–1e-14，说明首轮的残差确由分布未收敛造成。非极限场景 v0 与修订版的 r、K/Y、s 在 5 位小数上一致，所以修订不改变任何比较静态结论；v0 只在极限场景上错误（受约束比例 6.3% vs 0.24%，Gini 0.77 vs 0.61）。把 v0 标为 superseded 的处理正确。
- 代码细节（不阻塞）：`stationary_distribution` 里 `except Exception` 静默退回均匀初值，最终仍有 dist_converged 把关，可接受，但建议在退回时写 warning 日志。直接解后 `np.maximum(d, 0)` 截负，未检查被截掉的负质量量级，建议记录。
- 一般均衡：Brent xtol = rtol = 1e-12。市场出清相对残差 4e-14（baseline）到 3.4e-12（b2），极限 7e-10；资源约束残差 1e-13–1e-14，极限 9e-11；分布质量误差 ≤ 2.2e-16。
- 容差：全部非极限场景的出清残差 < 5e-12，已满足协议默认的 1e-8；spec §8 引用的"异质主体 + 一般均衡"放宽到 1e-6 并无必要，且理由（分布离散化误差）在修订分布例程后已不成立。建议把 `tol_ss` 收紧到 1e-8（极限场景 7e-10 同样满足），避免"为通过而放宽"的观感。
- Euler 误差：非约束点 log10 平均绝对相对误差 −5.37（b=8）至 −5.76（baseline）；b 越大略变差，因为网格相对更粗，仍然很好。极限场景 −7.63。最大误差 −1.9 至 −2.3（约 0.5%–1.2%）：这只是少数点上的最大值，加密网格也不改善（n_a=800 时 −2.46，n_a=1000/a_max=100 时 −1.84），不随网格收敛，更像取决于约束拐点邻近或尾部个别点（此归因我没有逐点验证，仅是假设）。建议报告均值 + 99 分位，不要报告 max 作为精度指标；对均值与总量无实质影响。

## 唯一性扫描

- 原扫描 15 点，所有场景只穿越 1 次。但 baseline 的 15 个点中有 13 个都在根左侧，穿越出现在最后一个区间 [0.0343, 0.0416]；该区间宽度占整个区间的 1/14，区间内部的多重穿越无法排除。上端点 K^s 受 a_max 截断，数值（+24.6）不是真值，只有符号有意义（K^s → ∞ 当 β(1+r) → 1）。
- 复核：我对 b = 0 与 b = 8 各做了 106 点细扫描（[−0.06, 0.03] 取 46 点，[0.03, r_hi] 取 60 点，加密在根附近）：均恰好穿越 1 次，括住根的区间分别是 [0.033663, 0.033856] 与 [0.036554, 0.036747]。b = 0 时超额供给严格单调递增。b = 8 在低 r 段 (K^s − K^d)/K^d 不单调（先降后升，最小约 −1.78），这是相对量在 K^s 为负时的分母效应，不影响唯一穿越。
- 结论：粗粒度唯一性成立，spec §9.7 的表述（只排除粗粒度多重穿越）准确。建议以后把扫描点加密到 60+，并向上端加密。

## 数值病态

- 参数风险：β(1+r) 均衡值 0.992（b=0）–0.995（b=8），接近 1 使 EGM 收敛慢、K^s(r) 在 r_hi 附近陡升；已由直接解分布与闭区间 Brent 处理，实际无病态。
- σ = 0.001 的极限检验使用 r_hi_eps = 1e-8；穿越点离上端点约 1e-6，仍在区间内部，通过是真实的而非区间端点造成。
- 未发现 nan / inf / 警告 / 错误日志（全部 log 只有 INFO；v0 的极限场景有 error 提示，已作废）。
- 不涉及 BK 条件、特征值、政策矩阵秩（本模型是稳态不动点问题，非摄动）。该项不适用。

## Tauchen 离散化质量（本次评议的重点）

### 事实

- 报告值：Var(log z) = 0.05483 vs 目标 0.04（偏高 37.1%，标准差 0.234 vs 0.2，偏高 17%）；一阶自相关 0.9016 vs 0.9（偏差 0.0016，可忽略）。
- 原因：spec 规定网格宽度 ±3σ_无条件（间距 = σ），而条件标准差 σ_ε = 0.436σ，间距 / σ_ε ≈ 2.3，区间中点法在这么粗的格点上系统性高估离散化后的方差，并非 bug。该偏差与 n_z 的关系：n_z = 15 时 Var = 0.0425（仍高 6%，自相关 0.8987）；n_z = 7 的偏差与 σ 无关（尺度不变）。
- spec §9.6 只要求"报告偏差"，没有阈值，所以字面上合规；但这是一个对研究问题有定量影响的偏差，不应只报告不处理。

b = 0 与 b = 8 之间（baseline → b8）的变化，对比不同离散化：

|---|---|---|---|---|---|---|---|---|---|---|
| Tauchen 7（原, m=3） | 0.0548 | 3.3703 | 3.1661 | 25.329 | 3.6668 | 3.0857 | 24.685 | +0.296 | −0.0804 | −0.644 |
| Tauchen 7, σ 调为 0.17093（方差配平） | 0.0400 | 3.5739 | 3.1104 | 24.884 | 3.7973 | 3.0515 | 24.412 | +0.223 | −0.0589 | −0.472 |
| Tauchen 15 | 0.0425 | 3.5429 | 3.1188 | 24.950 | 3.7791 | 3.0563 | 24.450 | +0.236 | −0.0625 | −0.500 |

| Rouwenhorst 15 | 0.0400 | 3.5766 | 3.1097 | 24.878 | 3.7995 | 3.0510 | 24.408 | +0.223 | −0.0587 | −0.470 |

- 水平偏差：基准 r 被低估约 0.20 个百分点（20 bp；3.37% vs 3.58%），K/Y 被高估 0.056（约 1.8%），s 被高估约 0.45 个百分点。绝对数字不能当作 σ = 0.2 的 Aiyagari 校准结果引用。
- 比较静态幅度：b 从 0 升到 8 的效应被高估约 33%–37%（Δr、ΔK/Y、Δs 的比值分别为 1.33、1.37、1.38），与方差膨胀倍数 1.37 几乎同比。符合直觉：预防性储蓄的强度近似正比于收入风险，二阶量被放大了。
- Rouwenhorst 7 与 15 状态几乎一致（r 差 0.002 pp），说明 Rouwenhorst-7 已收敛；同时 Tauchen-7 配平方差后和 Rouwenhorst 的水平差 0.005 pp 以内，证明偏差来自方差，而不是别的。
- 方向稳健性：用 Rouwenhorst-7 跑全部 b = 0, 0.5, 1, 2, 4, 8，r 严格单调上升（3.579, 3.609, 3.634, 3.677, 3.736, 3.801），K/Y 严格单调下降（3.1092, 3.1012, 3.0943, 3.0830, 3.0674, 3.0506），s 严格单调下降（24.873, 24.809, 24.754, 24.664, 24.539, 24.405）。Tauchen 原结果同样单调。因此 b↑ ⇒ r↑、K/Y↓、s↓ 的符号对离散化稳健；不稳健的是量级。
- 其他验收项：r < 1/β − 1 = 4.167%（所有离散化下 r ≤ 3.80%）；s > 23.67%（所有离散化下 ≥ 24.4%）；这两条定性结论同样稳健。受约束比例、Gini 对离散化较不敏感（Gini 0.475–0.478 vs b=0），但 n_z = 15 Tauchen 的受约束比例 1.85% 比 7 状态 2.78% 低，说明受约束质量与最低收入格点位置有关，不应解读为精确量。
- 备注（非数值问题，转交 model-reviewer）：b ≥ 2 时净资产含大量负值，`wealth_gini`（b=8 为 0.885）对含负值的净财富不是 [0,1] 内的标准基尼，不宜作为不平等度量写入结论。

### 判断与建议

1. 该偏差对本研究问题不可接受为"只报告"：研究问题的核心是比较静态的量级（K/Y、s 的变化），而量级被高估约 1/3，且水平差 20 bp 与整个 b 实验引起的 r 变动（0.22–0.30 pp）同量级。
2. 修改：把收入过程改为 Rouwenhorst（n_z = 7，保持与 Aiyagari 一致的状态数；增加 n_z = 15 作稳健性）。它精确匹配 AR(1) 的方差与自相关，适合 ρ = 0.9 这样的高持续性过程；本次实验已验证偏差消失（Var = 0.0400，自相关 0.9000）。
   - 备选：保留 Tauchen 但调整 σ 配平离散后方差（σ ≈ 0.1709）；该做法能恢复水平，但把 Tauchen 的偏差藏进参数里，不推荐作为主设定，仅可作稳健性。
   - 不推荐只增加 Tauchen 状态数：n_z = 15 仍高估 6%，要降到 <1% 需要明显更多状态，成本高。
3. 注意 Rouwenhorst 格点宽度为 ±σ√(n−1) ≈ ±2.45σ（而非 ±3σ），z_min 会变化，因此 spec §3.1 的自然借贷上限 w z_min / r 要重新报告（目前 17.6–19.4，远高于 b ≤ 8，预计仍成立，需复核）。
4. spec §9.6 应加入阈值（例如 |Var 比 − 1| < 2%，|自相关偏差| < 0.005），并把该判据纳入 solve.py 的 `validated`（当前 validated 不含离散化检查，所以 37% 的偏差下仍标为 True）。
5. 若时间不允许重跑整套：至少把论文数字分级，方向性结论可用，量级（Δr、ΔK/Y、Δs）须标注"在 Tauchen 离散下高估约 35%，已由 Rouwenhorst 复核"。
