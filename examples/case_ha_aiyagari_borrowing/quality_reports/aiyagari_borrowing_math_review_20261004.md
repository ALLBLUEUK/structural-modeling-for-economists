## 一、方程计数

稳态均衡对象分两层：

- 标量内生变量：r, w, K, Y，共 4 个（L = 1 由归一化给定，是参数，不是内生变量）。
- 函数/分布型内生对象：c(a,z), a'(a,z), Λ(a,z)。
- 方程：
  - (2) 预算约束，定义 c；
  - (1) Euler 不等式（含互补松弛），定出 a'；
  - (3) 平稳分布不动点，定出 Λ；
  - (4) K = ∫a dΛ 与 K = K^d(r)，两条；
  - (5) r 与 w 的要素价格公式，两条；
  - 生产函数 Y = K^α L^{1−α}，在 §3.2 给出，**未编入 §5**。
- 逐项配平：
  - r：由 K = K^d(r)（即 r 的逆需求形式）定出；
  - w：由 (5) 第二式定出；
  - K：由 K = ∫a dΛ 定出；
  - Y：由生产函数定出；
  - 函数对象：由 (1)(2)(3) 定出。
- 实质上"1 个未知价格对应 1 条出清方程"成立，GE 为一维根寻找，未知数与方程数一致。✅（实质一致）
- 但 spec 的写法有三处不严密：
  1. §5 方程 (4) 的需求侧 K^d(r) 与方程 (5) 第一式 r = αK^{α−1}L^{1−α} − δ 是**同一条条件的两种写法**（互为反函数）。若把二者都当独立方程，则 r 被两条方程同时决定，系统超定。须明确写成"r 的唯一决定式 = K(r) = K^d(r)，(5) 第一式仅用于事后恒等校验"。
  2. Y 出现在变量表却无方程。
  3. §5 的"维度自检"只数了价格，没有逐一列出 (r, w, K, Y) 对 (方程) 的配平。
- 结论：计数实质一致，但表述需修正（见必改 1）。

## 二、维度一致性

| 方程编号 | 含义 | 左端单位 | 右端单位 | 一致 |
|---|---|---|---|---|
| (1) | Euler 不等式 | u'(c)，1/c | β(1+r)·E u'(c')，1/c（β、(1+r) 无量纲） | ✅ |
| (2) | 预算约束 | c + a'，实物 | (1+r)a + wz，实物（w 为实物/效率单位，z 为效率单位） | ✅ |
| (3) | 平稳分布 | 测度 | 测度（T 为 Markov 算子） | ✅ |
| (4) | 资本市场出清 | K，实物 | L·(α/(r+δ))^{1/(1−α)}，L 为效率单位，括号内无量纲，实物/效率单位口径与 K/L 一致 | ✅ |
| (5a) | 资本回报 | r，年率 | α(K/L)^{α−1} − δ，无量纲/年 | ✅ |
| (5b) | 工资 | w | (1−α)(K/L)^α，实物/效率单位 | ✅ |
| (6) | AR(1) | log z'，无量纲 | ρ log z + ε'，无量纲 | ✅ |

- 要素价格公式独立重推：K^d(r) 由 r + δ = α(K/L)^{α−1} 得 K/L = (α/(r+δ))^{1/(1−α)}，与 (4) 一致 ✅；w = (1−α)K^αL^{−α} = (1−α)(K/L)^α ✅。
- 瑕疵：L = Σ_z z π(z) 要求 E[z] = 1（"归一化使 L = 1"），但 AR(1) 的对数过程给出 E[exp(log z)] ≈ exp(σ²/2) ≠ 1（0.2² / 2 = 0.02，约 1.02）。spec 没有写明归一化动作（z ← z / Σ z π）以及归一化相对于 z_min 的先后次序；而 φ_nat = w z_min / r 依赖归一化后的 z_min。见必改 3。

- 状态：a_t（t 期期初）、z_t（t 期期初，决策前已观察）。

## 四、FOC 推导抽查

- (1) Euler 不等式
  - 贝尔曼：V(a,z) = max_{a' ≥ −φ} u((1+r)a + wz − a') + β Σ Π(z,z') V(a',z')；
  - 一阶条件：−u'(c) + β Σ Π(z,z') V_a(a',z') + λ = 0，λ ≥ 0，λ(a' + φ) = 0；
  - 包络：V_a(a,z) = (1+r) u'(c(a,z))；
  - 代入得 u'(c) = β(1+r) Σ Π u'(c') + λ ≥ β(1+r) Σ Π u'(c')，λ > 0 仅当 a' = −φ。
  - 与 spec 不等号方向一致 ✅，互补松弛表述（"a' > −φ 时取等号"）✅。
- 借贷限额：φ = min{b, w z_min / r}。
  - 自然借贷限额的推导：在 z_min 永久持续、c ≥ 0 的最坏情形下，a_{t+1} ≥ −w z_min / r。该式在 **r > 0** 时成立 ✅。
  - 但：
    - 当 r ≤ 0 时 w z_min / r 为负或无定义（r = 0 时除零），φ = min{b, ·} 将得到负的借贷限额（相当于强制储蓄下限）或崩溃。
    - §8 的二分区间为 (−δ, 1/β − 1)，**显式包含 r ≤ 0 的区域**，求解器在迭代中必然访问到这些 r。
    - r ≤ 0 时自然限额不存在，应令 φ = b。见必改 2。
  - 另外，φ 依赖于 r（和 w），资产网格 [−φ, a_max] 须随 r 更新，spec 未说明。
- CRRA 在 μ = 3 下 u'(0) = ∞，保证 c > 0，限额取在自然限额之下时是严格的。✅
- 存在性条件：β(1+r) < 1 是 K(r) 有限的必要条件，二分上界取 1/β − 1 时恰好在边界上（见必改 4）。

## 五、稳态残差（解析）

- spec 未给出解析稳态，只给了完全市场基准。核算如下：
  - r* = 1/β − 1 = 1/0.96 − 1 = 0.0416667 ✅（= 4.167%）；
  - K/Y = α/(r* + δ) = 0.36 / 0.1216667 = 2.9589；
  - s = δK/Y = 0.08 × 2.9589 = 0.23671；
  - 另一写法：δα/(r*+δ) = 0.0288 / 0.1216667 = 0.23671。
  - 与 §9 的 23.67% **逐位一致 ✅**。
- 推导正确性：稳态下投资 = δK，故 s = δK/Y；K/Y = α/(r+δ) 来自企业一阶条件。因此 s = δα/(r+δ) 对 r 严格递减，r < r* ⇒ s > 23.67%，§9 的方向性命题成立 ✅。
- 前提说明：此基准仅在"完全市场/代表性主体、同一 β、同一技术"下成立，spec 应写明。
- 对 r < 1/β − 1：这是 Aiyagari (1994) 的已知结论，由 K(r) → ∞ (r → 1/β − 1) 决定。✅
- 对 §9 的"b 增大 → K 下降、r 上升（单调）"：理论方向正确（放松约束使 K(r) 曲线左移，K^d 递减），但"必然"与"单调"是数值检验目标而不是定理，建议措辞为"预期方向"。非必改。
- 事先量级核对（自然限额检查）：K ≈ 5–6 时 w ≈ 1.2，归一化后 z_min ≈ exp(−3×0.2)/1.02 ≈ 0.54（假设 Tauchen m = 3），r ≈ 4%，自然限额 ≈ 1.2 × 0.54 / 0.04 ≈ 16 ≫ 3。b = 1, 2, 3 均远低于自然限额，§9 最后一条会通过。✅（但见必改 3：m 未定）

## 六、冲击映射

- 本模型无总量冲击，无 varexo。个体冲击 ε' 通过 (6) 进入 z' 的转移，离散后通过 Π 进入 (1) 与 (3)。✅
- σ_ε 映射：
  - AR(1) 的无条件方差 Var(log z) = σ_ε² / (1 − ρ²)；
  - 令其等于 σ² 即 σ_ε = σ√(1 − ρ²) = 0.2 × √0.19 = 0.0872 ✅。
  - Tauchen 的网格宽度须按**无条件标准差 σ = 0.2**（±mσ）设置，而 Tauchen 的区间概率须按**条件标准差 σ_ε = 0.0872**计算。spec 只给了 σ_ε，没有说明网格宽度参数 m。见必改 3。
- 转移矩阵：每行和为 1、元素非负（Tauchen 构造保证），无协方差矩阵正定问题（一维冲击，σ_ε² > 0）。✅
