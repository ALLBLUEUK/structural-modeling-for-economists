## 1. 经济问题与机制

研究问题：在存在不可保险的个体劳动收入风险与借贷约束的 Aiyagari 经济中，借贷限额 b 的松紧如何影响均衡利率 r、总资本 K、资本—产出比 K/Y 与总储蓄率 s = δK/Y？

机制：家庭面对持续的个体收入冲击，只能通过一种无风险的净资产 a 自我保险。a 是家庭对企业资本的索取权与家庭间私人借贷（净供给为零）之和；a 可以为负（借款），但不得低于 −φ。为防止在低收入状态下撞上借贷约束，家庭进行预防性储蓄，使资本供给 K^s(r) 高于完全市场情形，压低均衡利率（低于 1/β − 1），提高 K/Y 与 s。借贷限额越紧，撞约束的风险越大，预防性储蓄越强；放松限额（b 增大）则一方面削弱预防性储蓄动机，另一方面允许部分家庭持有负资产，二者都使 K^s(r) 曲线左移，预期 K、K/Y、s 下降、r 上升。

与文献的距离：b = 0 的基准是对 Aiyagari (1994) 的复刻；b > 0 的比较静态是在同一框架内的扩展。借贷限额与无风险利率的关系也见 Huggett (1993) 的纯交换经济；本模型与之的区别是加入了生产与资本，利率由资本边际产出决定。

不包含的机制：无政府、无国外、无总量冲击、劳动供给无弹性；计价单位为产出品。

## 2. 时间环境

- 离散时间，期长度：年；无限期
- 不确定性来源：个体劳动效率冲击（无总量不确定性）
- 信息结构：家庭在 t 期观察自身 (a_t, z_t) 后决策；稳态下价格 (r, w) 为常数且已知

## 3. 代理人

### 3.1 家庭（连续统，测度为 1）
- 偏好：E_0 Σ β^t u(c_t)，u(c) = c^{1−μ}/(1−μ)
- 预算约束：c_t + a_{t+1} = (1 + r) a_t + w z_t
- 借贷约束：a_{t+1} ≥ −φ(r)，其中
  - r ≤ 0 时 φ(r) = b；
  - r > 0 时 φ(r) = min{b, w(r) z_min / r}（第二项为离散化下的自然借贷上限）
- 说明：自然上限依赖 Tauchen 截断后的 z_min（连续 AR(1) 下 z_min → 0、自然上限 → 0），因此它是离散化的产物，不是模型的经济量；报告中给出其数值以显示实验中的 b 远离该上限。
- 选择变量：c_t, a_{t+1}；状态变量：a_t, z_t

### 3.2 企业（代表性，完全竞争）
- 生产函数：Y = K^α L^{1−α}
- 资本需求与工资：K^d(r) = L (α/(r+δ))^{1/(1−α)}，w(r) = (1−α)(K^d(r)/L)^α

## 4. 变量与对象分类表

| 符号 | 类型 | 含义 |
|---|---|---|
| `a` | 个体状态（期初） | 净资产 |
| `z` | 个体外生 | 劳动效率，7 状态 Markov 链，转移矩阵 P，平稳分布 π_z |
| `c(a,z)`, `a'(a,z)` | 个体控制 | 消费与储蓄策略函数 |
| `Λ(a,z)` | 稳态分布 | 平稳联合分布 |
| `φ(r)` | 价格的函数 | 借贷下限（见 §3.1） |
| `r`, `w` | 价格 | 资本净回报、工资率 |
| `K^s(r)` | 总量 | 家庭净资产供给 = ∫ a dΛ |
| `K^d(r)` | 总量 | 企业资本需求 |
| `L` | 总量 | 有效劳动 = Σ z π_z(z) = 1（归一化） |
| `Y`, `C` | 总量 | 产出、总消费 |

## 5. 方程系统（内生对象—方程对应）

| 内生对象 | 方程 |
|---|---|
| c(a,z), a'(a,z) | (E1) Euler 不等式：u'(c(a,z)) ≥ β(1+r) Σ_{z'} P(z,z') u'(c(a'(a,z), z'))，a'(a,z) > −φ(r) 时取等号（互补松弛）；(E2) 预算约束 c + a' = (1+r)a + wz |
| Λ | (E3) Λ = T(Λ; a', P)，由储蓄策略与转移矩阵诱导的不动点 |
| w | (E4) w = (1−α)(K^d/L)^α |
| K^d | (E5) r = α (K^d/L)^{α−1} − δ（只使用一次） |
| r | (E6) 资本市场出清 K^s(r) = K^d(r) |
| Y | (E7) Y = (K^d)^α L^{1−α} |

总量层面 1 个未知价格 r 对应 1 条出清方程 (E6)；其余总量由 (E4)(E5)(E7) 递推。资源约束 C + δK = Y 由 Walras 律自动成立，作为验证项（§9）而非独立方程。

劳动效率过程：log z' = ρ log z + ε'，ε' ~ N(0, σ_ε²)，σ_ε = σ √(1−ρ²)。v3：按 numerics-reviewer 意见改用 Rouwenhorst 方法离散（n_z = 7，网格 ±√(n_z−1)·σ，精确匹配无条件方差与一阶自相关）；n_z = 15 作稳健性；Tauchen（m = 3）结果作为对照保留。取 z = exp(格点) 后整体缩放使 Σ z π_z(z) = 1，z_min 取缩放后的值。

## 8. 求解方法

- 家庭问题：内生网格法（EGM, Carroll 2006），消费策略 sup 范数容差 1e-10
- 资产网格：n_a = 400，在 [−φ(r), a_max] 上按幂次 2 向下端加密，a_max = 100（v3）；**每次更新 r 都按 φ(r) 重建网格**
- 平稳分布：Young (2010) 非随机模拟（彩票法），容差 1e-12
- 一般均衡：在闭区间 [r_lo, r_hi] = [−δ + 0.02, 1/β − 1 − 1e-4] 上用 Brent 法求 K^s(r) − K^d(r) = 0；出清相对残差 < 1e-8（v3 按 numerics-reviewer 建议收紧）
- 唯一性：在 [r_lo, r_hi] 上取 30 个点扫描（v3 加密） K^s(r) − K^d(r)，确认只穿越零点一次

## 9. 验证目标

1. 均衡利率 r < 1/β − 1 = 4.167%
2. 储蓄率 s = δK/Y 高于完全市场基准 δα/(1/β − 1 + δ) = 0.0288/0.12167 = 23.67%
3. 极限检验（替代与文献表格的数值对照；报告中注明未与表 II 逐格对照）：σ = 0.001 时单独取 r_hi = 1/β − 1 − 1e-8，通过阈值 |r − (1/β − 1)| < 1e-4 且 |s − 23.67%| < 0.1 个百分点；该检验中 9.1、9.2 的严格不等式不适用
4. 资源约束：|C + δK − Y| / Y < 1e-6
5. 平稳分布质量和为 1（误差 < 1e-12）；均衡处网格上端质量 < 1e-8
6. 离散化质量（v3 纳入 validated）：|Var(log z)/σ² − 1| < 5%，|自相关 − ρ| < 0.01
7. 唯一性扫描单次穿越（30 点扫描，只能排除粗粒度多重穿越，不构成唯一性证明）
8. 比较静态的**预期方向**（数值检验目标，非定理）：b 增大 → K、K/Y、s 下降，r 上升
9. 对均衡 r 报告自然借贷上限 w z_min / r 的数值，确认实验中 b 均低于它
10. Euler 方程误差：非约束点上的 log10 平均绝对 Euler 误差报告
